خط Thmanyah Sans — ملفات الخط غير مرفقة في هذا المستودع عمدًا
================================================================

رخصة الخط (Thmanyah Font License) تمنع إعادة توزيع ملفات الخط أو رفعها أو استضافتها على
أي موقع أو منصة (ومنها GitHub). لذلك حمّل الخط بنفسك من الموقع الرسمي لثمانية، ثم ضع
الملفات الخمسة التالية في هذا المجلد بنفس الأسماء بالضبط:

    ThmanyahSans-Light.otf     (وزن 300)
    ThmanyahSans-Regular.otf   (وزن 400)
    ThmanyahSans-Medium.otf    (وزن 500)
    ThmanyahSans-Bold.otf      (وزن 700)
    ThmanyahSans-Black.otf     (وزن 900)

بعدها أعد بناء التطبيق. الملفات تدخل داخل الـ APK فقط ولا تُرفع إلى Git (مستثناة في .gitignore).

إن لم تضع الخط يعمل التطبيق عادي، لكن النصوص تظهر بخط النظام الاحتياطي (Segoe UI / Tahoma / sans-serif)
بدل Thmanyah Sans.

للاستثناءات أو الاستفسار عن الترخيص: ask@thmanyah.com

---

Thmanyah Sans — font files are NOT included in this repository on purpose.
The font license forbids redistributing, uploading or hosting the font files on any website or
platform. Download the font from Thmanyah's official site and drop the five .otf files listed
above into this folder (exact filenames). They are git-ignored, so they will not be committed.
Without them the app still runs and falls back to a system font.
